## 🌟 Концепция проекта: «eGov для школьников Казахстана»

**Smart School KZ (Mektep Hub)** — это не просто школьный сайт, а высокотехнологичный SaaS-портал государственного масштаба в эстетике современных инструментов разработчика (Vercel, Supabase, Linear, Neon). Платформа объединяет 3D-навигацию по корпусам школы, адаптивное AI-расписание с защитой от перегрузок, академического наставника для подготовки к международным экзаменам, сервис экологического аудита и единое цифровое окно для учеников, педагогов и родителей.

## ⚡ Ключевые возможности платформы

### 1. 🧭 3D Интерактивная навигация по зданию школы (`/navigation`)
* **WebGL / Three.js движок**: Процедурный трехмерный рендеринг этажей 1–4, кабинетов, лестничных пролетов и коридоров.
* **Трассировка лучей (Raycasting)**: Выбор кабинета кликом по 3D-модели с подсветкой и всплывающими подсказками.
* **Построение маршрутов**: Поиск пути между кабинетами со сменой этажей (например, Каб. 101 на 1 этаже → Каб. 304 на 3 этаже).
* **Светящаяся трубка пути**: Визуализация трехмерной траектории движения в реальном времени.
* **Пошаговый регламент**: Точный расчет дистанции в метрах, времени перехода в минутах и пошаговые указания.
* **Обработка граничных ситуаций**: Проверка отсутствующих кабинетов (например, 999) с дружелюбным 안내-сообщением.

### 2. 📅 AI Генератор расписания & Smart Balance (`/schedule`)
* **NLP-генерация**: Составление недельного плана уроков по текстовому запросу естественным языком.
* **Строгое соответствие СанПиН РК**: Балансировка сложной когнитивной нагрузки (алгебра, физика) и активности (физкультура, творчество).
* **Стресс-тест Edge Case 3**: При аномальном запросе *"Хочу отдыхать каждый час с 08:00 до 20:00"* система не падает, а фиксирует нехватку времени, сохраняет академический минимум предметов и предлагает компромиссный вариант (**Smart Balance**).
* **Категории слотов**: Цветовая индикация `LESSON`, `BREAK`, `SPORT`, `CLUB`, `FREE`.

### 3. 🧠 AI Академический Ментор (IELTS & Анализ эссе) (`/mentor`)
* **Оценка по стандартам IELTS Academic**: Детальная оценка эссе по 4 международным критериям:
  * *Task Response* (Раскрытие темы и полнота аргументов)
  * *Coherence & Cohesion* (Логическая связность и структура)
  * *Lexical Resource* (Лексическое разнообразие и академический вокабуляр)
  * *Grammatical Range & Accuracy* (Грамматическая точность)
* **Аналитические метрики**: Подсчет слов, расчет времени чтения, итоговый балл (Band 1.0–9.0).
* **Качественные рекомендации**: Выделение сильных сторон, зон роста и конкретных фраз-связок (*«Furthermore»*, *«Consequently»*).

### 4. 🧪 Панель верификации для членов жюри (`/demo`)
* **Автоматизированный тест-сьют в 1 клик**:
  * **Тест 1**: Проверка алгоритма межэтажного 3D-маршрута (101 → 304).
  * **Тест 2**: Генерация стандартного расписания для 10 класса.
  * **Тест 3**: Стресс-тест перехвата коллизии Edge Case 3 (*«Отдых каждый час»*).
  * **Тест 4**: Анализ академического эссе через AI-ментор.
  * **Тест 5**: Загрузка и соответствие счетчиков Бюро находок (24/17/7).
  * **Тест 6**: Валидация эко-движка (1 284 кг бумаги, 42 800 цифровых справок).
* **Визуальные бейджи**: Индикация `PASS` / `FAIL`, время исполнения в миллисекундах и live-терминал с логами.

### 5. 🌿 Eco-Monitor Дашборд (`/eco`)
* **Официальные метрики**:
  * **1 284 кг бумаги** сохранено;
  * **42 800 цифровых документов** выдано через портал;
  * **37 живых деревьев** сохранено в парках Казахстана;
  * **96 200 литров воды** и **14 200 кВт·ч энергии** сбережено.
* **Интерактивные графики**: Recharts (AreaChart и BarChart) с динамикой по месяцам.
* **Анимированные счетчики**: Плавный счет цифр на базе GSAP.
* **Эко-калькулятор**: Расчет пользы от отказа от печати классных журналов и справок.

### 6. 🎒 Здоровье, Гидратация & Горные походы (`/activity`)
* **Трекер водного баланса**: Дневная норма 2.0 литра, интерактивная сетка стаканов, прогресс-бар и streak.
* **Протокол «20-20-20» для глаз**: 20-минутный рабочий таймер и 20-секундный отдых для защиты зрения учеников при работе с экранами.
* **Чек-лист экспедиции (Заилийский Алатау & Кок-Тобе)**: Интерактивный список обязательного и вспомогательного горного снаряжения с подсчетом веса рюкзака.
* **Спортивные секции**: Электронная запись в школьные лиги (баскетбол, волейбол, робототехника, шахматы).

### 7. 🛟 Единая служба «Куда обратиться?» (`/help`)
* **NLP-классификатор ситуаций**: Автоматическое определение ответственного кабинета (Медпункт 102, Охрана 101, Психолог 215, Приемная 201, IT 301, Столовая 105).
* **Пошаговый регламент действий**: План для школьника с контактами и временем решения вопроса.
* **Мгновенный переход**: Кнопка «Показать в 3D навигаторе» для открытия маршрута.
* **Экстренная линия 111 (SOS Modal)**: Телефон доверия для защиты прав детей Республики Казахстан.

### 8. 📦 Цифровое Бюро находок (`/lost-found`)
* **Статистика**: 24 зарегистрировано, 17 возвращено владельцам, 7 ожидают на складе.
* **Фильтрация и поиск**: Поиск по названию, локации и категориям (электроника, одежда, книги).
* **Форма добавления находки**: Валидация полей, генерация уникального ID (LF-xxx) и моментальное обновление витрины.

### 9. 📢 Лента объявлений (`/announcements`)
* **Фильтрация**: По категориям (`academic`, `health`, `eco`, `tech`, `culture`).
* **Приоритеты**: Цветовая индикация срочности (High, Medium, Low).
* **Связка с навигацией**: Клик на локацию автоматически прокладывает маршрут к нужному кабинету.

## 🚀 Быстрый старт (Local Development)

### 1. Клонирование репозитория и установка зависимостей
```bash
git clone https://github.com/your-username/smart-school-kz.git
cd smart-school-kz
npm install
```

### 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```

### 3. Запуск фронтенда и бэкенда одновременно
Команда запускает Express API на порту `5000` и Vite Dev Server на порту `5173`:
```bash
npm run dev:all
```

* 🌐 **Фронтенд**: `http://localhost:5173`
* 🔌 **Бэкенд API**: `http://localhost:5000/api`
* 🩺 **Health Check**: `http://localhost:5000/api/health`

### Запуск по отдельности (при необходимости):
```bash
# Только фронтенд (с локальным fallback-слоем):
npm run dev

# Только Express сервер:
npm run server
```

Вы можете протестировать проект двумя способами:

## 📡 Спецификация REST API

### Эндпоинты:
* `GET /api/health` — проверка работоспособности сервера.
* `GET /api/rooms` — получение списка всех кабинетов школы с координатами.
* `POST /api/navigation/route` — расчет пути между кабинетами:
  ```json
  // Request
  { "from": "101", "to": "304" }
  ```
* `GET /api/schedule` — получение актуального расписания.
* `POST /api/schedule/generate` — генерация расписания по промпту (с перехватом коллизий).
* `POST /api/mentor/analyze` — анализ текста эссе по критериям IELTS.
* `GET /api/lost-found` — список находок и статистика (24 найдено, 17 возвращено, 7 ожидают).
* `POST /api/lost-found` — регистрация новой находки.
* `GET /api/eco` — статистика сохраненных ресурсов и данные графиков.
* `POST /api/help/classify` — классификация вопроса ученика.

## ☁️ Развертывание (Deployment)

### Развертывание на Vercel (Production Ready)
Проект полностью укомплектован файлом `vercel.json` со всеми правилами rewrites для Single Page Application.
1. Подключите репозиторий в панели Vercel.
2. Build Command: `npm run build`
3. Output Directory: `dist`
4. Нажмите **Deploy**.

> **Примечание об отказоустойчивости:** В клиентский слой `src/services/` встроен надежный автономный fallback-движок. Даже если Express бэкенд не запущен или платформа развернута в виде статического сайта, все функции (3D-навигатор, генератор расписания, AI-ментор, эко-калькулятор) работают на 100% стабильно без ошибок.
